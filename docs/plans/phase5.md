### Фаза 5 — GitHub Actions
**Статус: завершена 04 ноября 2026г.**

Цель: воспроизводимый CI на hosted runner, без Selenoid.

До реализации согласуйте: события запуска, артефакты vs
опубликованный сайт, переопределяемые параметры.

- Явная подготовка: Java, браузер, драйвер, CLI отчёта.
  Не предполагайте, что нужный браузер уже установлен;
  сверяйте версию ChromeDriver с браузером и поддержкой CDP.
- Actions закрепляйте по SHA; `permissions` — минимальные;
  secrets коду fork PR не давать, `pull_request_target`
  для запуска кода не использовать.
- После падения сохраняйте JUnit XML, Allure results
  с вложениями и готовый отчёт — но job остаётся failure.
- Отделяйте ошибку компиляции от падения тестов;
  без результатов отчёт не генерируется («0 тестов» — не успех).

Проверка: реальный запуск в вашем GitHub — success;
контролируемое падение и ошибка сборки показывают
правильные статусы и нужные артефакты (временные ветки
удалите после проверки).

Ловушки AI: Chrome на hosted runner может требовать
`--no-sandbox` (принимайте компромисс осознанно, только для CI,
задокументируйте риск); dispatch-only workflow может не
индексироваться GitHub до первого push-триггера — проверяйте
фактическую регистрацию; Pages environment допускает
только заявленные ветки.
