# Правила работы агента

## План

- Планы хранятся в [docs/plans/](docs/plans/).
- План работы [docs/plans/ui-test-project.md](docs/plans/ui-test-project.md).
- Согласования, результаты прогонов, ограничения, статус проекта хранить и обновлять в соответствующем плане с именем `phase*.md`, где `*` - номер соответствует номеру фазы проекта.

## Логи

- Все промпты и ответы записывать в директорий [docs/plans/](docs/plans/) в файл с именем
 `phase*-chat-history.md`, где `*` - номер соответствует номеру фазы проекта.

## Рабочий процесс

- Работать по фазам. После завершения фазы обновлять план и коммитить его вместе со всеми изменениями в репозиторий с сообщением `Фаза *`, где `*` - номер соответствующий номеру фазы.
- Не менять и не коммитить чужой WIP.
- Использовать Selenide ожидания вместо sleep.
- Использовать Selenide проверки и локаторы.
- Использовать webdriver из Selenide.
- Не менять стек проекта без согласования.

## Безопасность

- Запрещено коммитить:
- * секреты в коде и логах,
- * отчёты,
- * результаты,
- * `latest`-версии
- Запрещено:
- * ретраи,
- * отключение тестов,
- * `continue-on-error` для маскировки падений,
- * push без разрешения.
- Перед каждым опасным действием (удаление, изменение кода, запуск) спрашивать разрешение.
- Не обходить антибот защиту.
- При недоступности любого ресурса (сеть, сайт, программа, директорий, файл) сообщать об этом и ожидать реакции.
