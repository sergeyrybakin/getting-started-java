# Правила работы агента

## Рабочий процесс

- Ты являешься автономным агентом-кодировщиком. У тебя есть доступ к инструменту терминал.
- Ты должен использовать предложенные tool calls для исполнения в терминале.
- Если ты должен выполнить команду, используй инструмент немедленно. Не застваляй пользователя 
  выполнить её вручную!
- Работать по фазам. После завершения фазы обновлять план и коммитить его вместе со всеми 
  изменениями в репозиторий с сообщением `Фаза *`, где `*` - номер соответствующий номеру фазы.
- Не менять и не коммитить чужой WIP.
- Использовать Selenide ожидания вместо sleep.
- Использовать Selenide проверки и локаторы.
- Использовать webdriver из Selenide.
- Не менять стек проекта без согласования.
- По завершении фазы производить коммит. Запоминать хэш коммита и сохранять его в файле 
  `docs/logs/phase*.md` в строке `## Статус: завершено (2026-11-07) ` + запомненный хэш коммита.

## План

- Планы хранятся в [docs/plans/](docs/plans/).
- План работы [docs/plans/plan_phase*.md](docs/plans/plan_phase*.md), где `*` - номер соответствует
  номеру фазы проекта.
- Согласования, результаты прогонов, ограничения, статус проекта хранить и обновлять в 
  соответствующем плане с именем `phase*.md`, где `*` - номер соответствует номеру фазы проекта.

## Логи

- Все промпты и ответы записывать в директорий [docs/logs/](docs/plans/) в файл.
- Так как произошло ветвление проекта, то в имени файла вторым словом должно быть название ветки,
  например, `phase3-lispublika-qwen3_8b-chat-history.md`, где:
  - phase3 - имя и номер фазы.
  - lispublika - имя ветки проекта.
  - qwen3_8b - имя языковой модели, с чьей помощью производилась работа.
  - chat-history.md - это описание содержимого файла.

## Безопасность

- Запрещено коммитить:
- * секреты в коде и логах,
- * отчёты,
- * результаты,
- * `latest`-версии
- Запрещено:
- * ретраи,
- * отключение тестов,
- * `continue-on-error` для маскировки падений,
- * push без разрешения.
- Перед каждым опасным действием (удаление, изменение кода, запуск) спрашивать разрешение.
- Не обходить антибот защиту.
- При недоступности любого ресурса (сеть, сайт, программа, директорий, файл) сообщать об этом и ожидать реакции.
